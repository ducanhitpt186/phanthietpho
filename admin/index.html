📦 Tải tệp lên GitHub Releases

Ghi chú: tệp lớn (phần mềm .exe, video, PDF…) để ở GitHub Releases – miễn phí, mỗi tệp tới 2 GB, không giới hạn lượt tải. Tải lên xong thì sao chép link để dán vào tiện ích hoặc gửi cho khách.

⬆ Tải tệp lên (bản v1) 📄 Xem tệp đã đăng ＋ Tạo bản phát hành mới 🗂 Tạo kho chứa tệp (lần đầu)
  1. Bấm ⬆ Tải tệp lên → trang GitHub mở ra (đăng nhập GitHub nếu được hỏi).
  2. Kéo tệp vào khung Attach binaries by dropping them here…, chờ chạy xong → bấm Update release.
  3. Ở mục Assets: máy tính thì chuột phải vào tên tệp → Sao chép địa chỉ liên kết; điện thoại thì nhấn giữ tên tệp → Sao chép liên kết.
  4. Dán link vào ô Liên kết của tiện ích (tick Đây là link tải tệp) hoặc gửi thẳng cho khách.

Lần đầu dùng: bấm 🗂 Tạo kho chứa tệp → chọn Public, tick Add a README file → Create repository. Sau đó bấm ＋ Tạo bản phát hành mới → Choose a tag gõ v1 → Create new tag → kéo tệp vào → Publish release.

Quản lý dữ liệu

Ảnh icon đang lưu trên kho GitHub. Ảnh “Không dùng” không còn gắn với tiện ích nào, có thể xóa cho nhẹ. Khi xóa tiện ích hoặc đổi icon, ảnh cũ được xóa khỏi kho tự động.
